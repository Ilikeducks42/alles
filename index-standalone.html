Neigung

Quelle: Maus / Tasten

Halte das Gerät so, wie es sich für dich neutral anfühlt, und tippe auf Kalibrieren. Diese Haltung gilt dann als geradeaus.

Bereit

Ultra einfach — ohne Terminal, ohne Server:
1. Tippe auf Code erzeugen.
2. Beide Geräte ins gleiche WLAN.
3. Auf dem Controller denselben 4-stelligen Code eintippen — fertig.

– – – –

Internet wird nur einmal zum Finden benutzt. Die Neigung läuft danach direkt von Handy zu Handy.

Ohne Internet: Code kopieren (Fallback)
